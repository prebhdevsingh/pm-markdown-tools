Excel to Markdown Converter

Instructions

  1. Select and copy a table from Excel (Ctrl+C or Cmd+C)
  2. Paste the table into the input area below (Ctrl+V or Cmd+V)
  3. Click "Convert to Markdown" button or press Ctrl/Cmd + Enter
  4. Copy the generated Markdown from the output area
